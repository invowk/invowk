# Table e Spin

Componentes de exibição de dados e indicador de carregamento.

## Table

Exibir e opcionalmente selecionar de dados tabulares.

### Uso Básico

<Snippet id="tui/table-basic" />

### Opções

| Opção | Descrição |
|-------|-----------|
| `--file` | Arquivo CSV para exibir |
| `--separator` | Separador de coluna (padrão: `,`) |
| `--columns` | Cabeçalhos de coluna (sobrescreve cabeçalho do arquivo) |
| `--widths` | Larguras de coluna (inteiros separados por vírgula) |
| `--selectable` | Permitir seleção de linha |
| `--height` | Altura da tabela |

### Exemplos

<Snippet id="tui/table-examples" />

### Saída Redirecionada

Quando stdout não é um terminal, uma tabela sem `--selectable` não abre. Ela mostra as linhas como texto simples e sai com 0, com ou sem terminal:

```bash
$ printf 'name|age|city\nAlice|30|NYC\nBob|25|LA\n' | invowk tui table --separator '|' | cat
name   age  city
Alice  30   NYC
Bob    25   LA
```

A primeira linha traz os títulos das colunas (a linha de cabeçalho ou `--columns`), depois uma linha por registro. As células ficam alinhadas à esquerda e preenchidas até a célula mais larga da coluna, as colunas são separadas por dois espaços, e não há borda nem cor. Uma quebra de linha, tabulação ou outro caractere de controle numa célula sai como espaço, assim como um caractere de formatação (por exemplo, uma marca de direção bidirecional ou um espaço de largura zero) e o separador de linha ou de parágrafo U+2028 ou U+2029, então cada registro fica numa linha só e se lê na ordem em que foi gravado. Uma sequência de bytes que não é UTF-8 válido sai como U+FFFD (�). Todas as linhas são mostradas: `--height` e `--widths` não se aplicam. Uma tabela selecionável continua desenhando no terminal, então `row=$(invowk tui table --selectable ...)` funciona como antes.

## Spin

Mostrar um spinner enquanto executa um comando longo.

### Uso Básico

<Snippet id="tui/spin-basic" />

### Opções

| Opção | Descrição |
|-------|-----------|
| `--title` | Título/mensagem do spinner |
| `--type` | Tipo de animação do spinner |

### Tipos de Spinner

Animações de spinner disponíveis:

- `line` - Linha simples
- `dot` - Pontos
- `minidot` - Pontos pequenos
- `jump` - Pontos pulando
- `pulse` - Ponto pulsante
- `points` - Pontos
- `globe` - Globo girando
- `moon` - Fases da lua
- `monkey` - Macaco
- `meter` - Medidor de progresso
- `hamburger` - Menu hamburger
- `ellipsis` - Reticências

### Tratamento de Código de Saída

O comando spin retorna o código de saída do comando encapsulado:

<Snippet id="tui/spin-exit-code" />

Outros resultados:

- **Ctrl+C.** Pressionar Ctrl+C enquanto o spinner aparece para o comando encapsulado, mostra a saída que ele produziu até ali e sai com status `1`, o status que qualquer comando invowk cancelado dá. Só o comando que o spin iniciou é parado: processos que ele mesmo iniciou podem continuar rodando. No Windows, um comando que é um script `.cmd` ou `.bat`, como o `npm`, roda sob o `cmd.exe`: só o `cmd.exe` é parado, e a ferramenta que ele iniciou pode continuar rodando.
- **Um comando que não para.** Se o comando não terminou 15 segundos depois de ser parado, o spin sai com status `1`, não mostra nada dele e avisa em stderr que ele pode continuar rodando.
- **Um comando morto por um sinal.** Um comando que termina sem status de saída, porque um sinal o matou, faz o spin mostrar a saída dele e sair com status `1`.
- **Uma falha do spinner.** Se o spinner não consegue desenhar depois que o comando começou, o comando continua rodando. O spin então mostra a saída e sai com o status dele, e o erro do spinner vai para stderr como aviso.
