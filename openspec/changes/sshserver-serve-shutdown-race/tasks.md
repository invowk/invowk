# Tasks

All paths are under the worktree `/var/home/danilo/Workspace/github/invowk/invowk-sshrace`. New tests go in a new file, `internal/sshserver/server_lifecycle_race_test.go`, so `server_test.go` (659 lines) stays well under the 1000-line limit.

Dial assertions ("the port refuses a dial") dial once per test, after `Stop` and any overlapping `Start` have returned, with a bounded `net.DialTimeout` (a refused loopback connect takes about 2 s on Windows), and expect a refusal (design.md, Risks). They dial only an address the test captured through `beforePublish` (the listener was bound). "Wait() returns" means `Wait()`, called only after `Start` has returned (D12), returns within a bounded time (a few seconds) in a goroutine the test waits on. Every test that holds a hook also releases it from `t.Cleanup` (D7), so a failing assertion never leaves a goroutine blocked. Errors are compared with `errors.Is` or `errors.As` against a sentinel or type, never by message text.
